# Japan Size Converter

Convert Japanese clothing and shoe sizes to US, UK, EU, and AU instantly.

**Live:** https://humancronadmin.github.io/japan-size-converter/

## Features

- Tops, Bottoms, and Shoes size conversion
- Men's and Women's sizes
- US, UK, EU, AU support
- Mobile-friendly, no install needed
- Data based on JIS standards

## Why?

Japanese sizes run 1-2 sizes smaller than Western sizes. This tool helps you find the right fit before you buy.
